Kullanılan Modeller

  • llama3.1:8b — Duygu analizi ve film önerisi
  • movie-agent — Tür sınıflandırma (fine-tuned)
  • mood_map.json — Tür → ruh hali (deterministik)
  • Ollama — Lokal LLM runtime

llama3.1:8b Özellikleri

  • Parametre sayısı: 8 milyar
  • Model türü: Instruction-tuned
  • Context window: 128K token
  • Dil desteği: Türkçe dahil 8+ dil

5 Ruh Hali Kategorisi

  • fun — Eğlenceli, hafif, güldüren
  • adrenaline — Aksiyon, gerilim, heyecan
  • emotional — Duygusal, dramatik, yoğun
  • comfort — Rahatlatıcı, sıcak, tanıdık
  • thought-provoking — Felsefi, derin, düşündürücü

API Endpoint

  • POST /api/find
  • Input: Türkçe metin (min 10 karakter)
  • Output: emotion + recommendation + genres + moods
  • Süre: 8–12 saniye (3 LLM çağrısı)
Eğitim Süreci — Kronolojik
1
Veri Seti: MPST (Movie Plot Synopses with Tags)
8.043 film özeti · 71 tür etiketi · Kaggle üzerinden temin edildi · %80 eğitim / %10 validasyon / %10 test
2
Eğitim Ortamı: Google Colab T4 GPU
16 GB VRAM · 25 GB RAM · PyTorch 2.x + HuggingFace Transformers + TRL 0.22
3
Base Model: Meta-Llama-3.1-8B-Instruct
8 milyar parametre · Instruction-tuned · 15 trilyon token eğitim verisi
4
Eğitim: SFTTrainer (Supervised Fine-Tuning)
3 epoch · 1.000 step · batch size 8 · learning rate 5e-4 · warmup steps 100 · loss: response_only
5
Değerlendirme
Validation seti: 804 örnek · Her 100 step'te değerlendirme · Tür sınıflandırma doğruluğu: ~%85
6
Dağıtım: Ollama Modelfile
HuggingFace → GGUF dönüşümü (~4 GB) · Ollama ile lokal deploy · temperature 0.1 · max 40 token
